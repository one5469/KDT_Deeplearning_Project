# OP.GG 통계 기반 게임 시간 추정

리그 오브 레전드 통계를 활용한 3인 팀 프로젝트에서 챔피언 통계와 게임 시간의 관계 분석 및 회귀 모델 실험을 담당했습니다.

- 기간: 2024.03.19–2024.03.20
- 담당: 권혁원 / 통계 데이터 전처리, 게임 시간 추정 모델
- 데이터: OP.GG에서 수집한 챔피언별 통계 데이터
- 기술: Python, pandas, scikit-learn, PyTorch

## 담당 작업 및 구현

- HDF 데이터의 중첩된 챔피언 통계를 표 형태로 정리하고 상위 챔피언 데이터 병합
- 게임 수, 승·패, 데스, 골드, OP Score 등과 게임 시간의 관계 탐색
- 이상치 필터링 및 StandardScaler를 이용한 입력 정규화
- 통계 변수 조합과 K/D/A 변수 조합을 각각 입력으로 구성
- PyTorch Dataset·DataLoader와 학습·검증·테스트 분할 구성
- 선형 계층으로 구성한 회귀 모델을 학습하고 MSE·MAE·MAPE로 비교
- 정규화 여부와 입력 변수 구성에 따른 결과 비교
